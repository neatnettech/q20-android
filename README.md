# q20-android

Android 6.0 on the BlackBerry Classic (Q20), which runs QNX.

## Structure

* `docs/` notes, specs, and findings
* `research/` per-subsystem reverse engineering notes
* `android/android-6.0/` Android 6.0 source snapshots
* `qnx/` QNX layer work (libc, ipc, memory, threading, networking, filesystem)
* `runtime/` ART, libcore, and dynamic linker
* `framework/` Android framework pieces
* `tests/` integration and unit tests
* `tools/` build and debugging helpers
