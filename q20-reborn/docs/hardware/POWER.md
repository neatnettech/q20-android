# Power architecture

## Battery

Replaceable. USB-C PD charging. Bench phase uses a lab PSU and electronic
load before the battery pack is selected.

## Isolation switches

Kill switches are power switches: dedicated load switches cut subsystem
power (modem, Wi-Fi/BT, mic bias, camera). See
security/RADIO_ISOLATION.md.
